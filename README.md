# متجر رونق - Rawnaq Luxury Storefront

متجر إلكتروني فاخر مكتمل وجاهز للبيع كمنتج نهائي، قابل للنقل الكامل إلى مالك جديد بدون اعتماد تقني على المطور بعد التسليم.

## 1) الصفحات الأساسية

### العربية

- `index.html`
- `products.html`
- `about.html`
- `privacy.html`
- `terms.html`
- `returns.html`
- `contact.html`
- `checkout.html` (واجهة دفع آمنة)
- `admin.html` (لوحة تحكم سهلة)

### الإنجليزية

- `en/index.html`
- `en/products.html`
- `en/about.html`
- `en/privacy.html`
- `en/terms.html`
- `en/returns.html`
- `en/contact.html`
- `en/checkout.html`
- `en/admin.html`

## 2) دعم اللغتين AR/EN

- تبديل سريع بين العربية والإنجليزية من الهيدر
- حفظ اللغة المختارة تلقائيًا
- محتوى مترجم باحترافية لكل الصفحات (وليس ترجمة آلية حرفية)
- كتالوج المنتجات يدعم اللغتين (اسم/تصنيف/وصف/شارات)

## 3) الهوية البصرية والشعار

- الأسلوب: **Minimal Luxury**
- الألوان: أسود ملكي + ذهبي هادئ + أبيض
- ملفات الشعار:
  - `assets/brand/logo.svg`
  - `assets/brand/logo.png`
  - `assets/brand/logo-icon.svg`
  - `assets/brand/logo-icon.png`

## 4) الدفع والموثوقية

- واجهة دفع مخصصة في `checkout.html`
- طرق الدفع المهيأة:
  - البطاقات البنكية
  - Apple Pay
  - مدى
- شارات أمان وثقة داخل صفحة الدفع
- إعدادات الدفع ضمن `assets/js/config.js` تحت `payment`

## 5) كتالوج المنتجات

- عدد المنتجات: **80 منتج**
- لكل منتج:
  - اسم تسويقي (AR/EN)
  - وصف طويل احترافي (AR/EN)
  - سعر أصلي + سعر مخفّض
  - تصنيف واضح (AR/EN)
  - SKU + حجم + تركيز

## 6) لوحة التحكم (بدون خبرة تقنية)

- `admin.html` و `en/admin.html`
- يمكن من خلالها:
  - تعديل بيانات المتجر
  - تعديل بيانات المنتجات
  - تصدير نسخة احتياطية كاملة
  - استيراد نسخة احتياطية
  - استعادة القيم الافتراضية

## 7) قابلية نقل الملكية

البنية مبنية كـ Static Storefront مستقل:

- يمكن رفعه على أي استضافة Static
- لا توجد تبعية لخادم خاص بالمطور
- جميع البيانات قابلة للنقل كنسخة احتياطية
- إعادة التسمية ممكنة من:
  - `assets/js/config.js`
  - أو مباشرة من لوحة التحكم

## 8) الأداء والجوال

- التصميم Mobile-First
- ملفات خفيفة بدون إطار عمل ثقيل
- JavaScript مؤجل `defer`
- تحسينات واجهة تقلل الحمل وتحافظ على تجربة سريعة

## 9) التشغيل

يمكن تشغيل المشروع مباشرة بفتح `index.html` أو رفع الملفات على:

- Netlify
- Vercel (Static)
- GitHub Pages
- cPanel static hosting
