# متجر رونق - Luxury Perfume Storefront

متجر إلكتروني فاخر جاهز للبيع كمنتج نهائي، مخصص لسوق العطور في الخليج، ببنية مستقلة قابلة للنقل الكامل لأي عميل.

## 1) مكونات المشروع

- `index.html` الصفحة الرئيسية الاحترافية (بانر فاخر + ثقة + FAQ + تسويق)
- `products.html` صفحة المنتجات (80 منتج + تصنيفات + بحث + ترتيب)
- `about.html` صفحة من نحن
- `privacy.html` سياسة الخصوصية
- `terms.html` الشروط والأحكام
- `returns.html` سياسة الاسترجاع
- `contact.html` صفحة تواصل معنا

## 2) الهوية البصرية

- اسم المتجر الافتراضي: **رونق**
- الأسلوب: **Minimal Luxury**
- الألوان: أسود ملكي + ذهبي هادئ + أبيض
- الشعار:
  - `assets/brand/logo.svg` (شعار نصي + أيقونة زجاجة)
  - `assets/brand/logo.png`
  - `assets/brand/logo-icon.svg`
  - `assets/brand/logo-icon.png`

## 3) تغيير اسم المتجر بعد الشراء (اختياري)

لتغيير الاسم والبيانات لاحقًا بسهولة:

1. افتح الملف `assets/js/config.js`
2. عدّل القيم التالية:
   - `name`
   - `tagline`
   - بيانات `contact`
3. (اختياري) استبدل ملفات الشعار داخل `assets/brand`

> بهذه الطريقة يمكن نقل المتجر بالكامل للمشتري بدون إعادة برمجة.

## 4) المنتجات

- عدد المنتجات: **80 منتج**
- كل منتج يتضمن:
  - اسم تسويقي جذاب
  - وصف عطري طويل
  - سعر أصلي وسعر مخفّض
  - تصنيف واضح
  - SKU وحجم وتركيز

## 5) الجاهزية الفورية للبيع

هذا المشروع:

- منتج نهائي مكتمل الصفحات والنصوص
- قابل لنقل الملكية بالكامل
- لا يعتمد على البائع بعد التسليم
- متجاوب 100% مع الجوال
- خفيف وسريع (HTML/CSS/JS بدون إطار ثقيل)

## 6) التشغيل

يمكن التشغيل مباشرة بفتح `index.html` أو رفع الملفات على أي استضافة Static مثل:

- Netlify
- Vercel (Static)
- GitHub Pages
- أي استضافة cPanel

---

تم بناء هذا المتجر بمستوى وكالة تصميم احترافية ليكون جاهزًا للبيع والتشغيل الفوري.
